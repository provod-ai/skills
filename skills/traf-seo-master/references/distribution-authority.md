# Distribution, authority and arbitrage research

Give each asset an actual source-of-attention hypothesis before producing a large batch. Owned hubs/docs/tools, working integrations/examples, partner documentation, relevant editorial stories and communities serve different audiences. A directory listing, GitHub star or publicly posted link is not proof of indexed discovery, qualified visits or conversion. Separate organic, referral, social, AI and paid channels; don't count the same journey several times.

Inspect real winning and losing pages for the chosen market/intent and record host history, link/mention sources, audience, page utility, date, actual metric versus estimate and costs. Adapt the useful demand/format/distribution mechanism with original evidence. A temporal link between a competitor change and growth does not isolate cause. Do not copy gated assets or claim access/tool availability from a gallery preview.

## High-risk and capital-dependent mechanisms

Research publisher/parasite authority, useful hosted UGC, aged/expired domains, legitimate acquisition/migration/reclamation, placements/niche edits/PBN economics and digital PR with explicit assets, outcome evidence, attrition, time-to-capture and correlated exposure. A domain metric or quoted valuation is not realized revenue or retained traffic. A one-day failed-page sample is not a lifetime ban probability. Segment affected path/engine/searcher geography and actual policy version; no global banned-bit or guaranteed domain-rotation recovery.

Link survival and quality vary by portfolio; a pooled mean hides concentrated losses. Keep placement/source, real audience, relevance, index status, terms, observation dates, cost and removal state. A Common Crawl CDX query for a site's own captures is not automatically an inbound-backlink database; use the appropriate current web graph/vendor dataset and preserve technical-link/host/domain scope limits.

RSOC/search-feed arbitrage is a separate paid acquisition-to-monetization P&L. Record spend, finalized payout, clawbacks, margin versus ROI, policy/creative/landing/result versions and account feature state. It is not credited toward an organic-visit goal. Conflicting current examples must be reconciled against the relevant owning rule before implementation; schema-valid does not guarantee business-semantic validity. This package does not contain an activated ad/feed engine or authorize spend.

External posts, contacts, purchases, links or provider changes require the task's actual scoped authority. Existing authorized same-contour/cap work continues without repetitive permission, but installation/research doesn't grant a campaign. Preserve receipts and possible-send UNKNOWN; don't send again because a callback timed out. Use the actual platform's documented flow, not guessed private endpoints.

Output a concrete distribution/authority opportunity map, evidence and costs, allowed next actions and a measured contribution hypothesis. Keep read-only research useful while a specific external action is unavailable. Relevant sources: [Google spam policies](https://developers.google.com/search/docs/essentials/spam-policies), [site reputation update](https://developers.google.com/search/blog/2026/08/update-site-reputation-policy), [site move flow](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes), [Common Crawl graphs](https://commoncrawl.org/web-graphs).

## Observe link state precisely

Distinguish an accessible source page without the target link, source 404/410, JS-unverifiable content, 5xx, 403/429, timeout and head-only evidence. Retain actual anchor/href/rel, page directives and date. A failed source fetch does not establish removal; successful HEAD does not establish survival. Any disavow decision needs current guidance and separate action authority. [Google disavow guidance](https://support.google.com/webmasters/answer/2648487).
