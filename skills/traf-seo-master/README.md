# TRAF SEO Master

Portable AgentSkills entry for multi-source SEO work across one site or hundreds of enrolled sites.

Use [bootstrap.md](bootstrap.md) for project-local installation and [SKILL.md](SKILL.md) for task routing. [Site audits](references/site-audits.md) takes a site profile through actual native checks, evidence reuse/import, findings, permitted fixes/readback and portfolio missing work. Every site uses the same registry; applicability and evidence stay site-specific. The helper's offline report is one stage, not audit completion.

Heavy dependencies, provider keys, a scheduler and a task database are not bundled. Instruction/source coverage, actual checks, authenticated evidence, indexing and acquisition remain distinct.
